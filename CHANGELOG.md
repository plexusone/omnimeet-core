## [v0.2.0] - 2026-10-27

### Highlights

- Attend Zoom, Google Meet, and Teams meetings hosted by others by phone dial-in from their invitation
- Attendee session interfaces shared by dial-in and future browser and SDK connectors

### Added

- `attendee` package: `Joiner`, `Session`, optional audio, recorder, and participant interfaces, `Capabilities`, and session states ([`2821b6d`](https://github.com/plexusone/omnimeet-core/commit/2821b6d))
- `dialin` package: dial-in number selection and keypad sequences for Zoom, Google Meet, and Teams ([`6cea6be`](https://github.com/plexusone/omnimeet-core/commit/6cea6be))
- `invite` package: parse Zoom, Google Meet, and Teams invitations and `.ics` files ([`489fe65`](https://github.com/plexusone/omnimeet-core/commit/489fe65))
- `dialin.Joiner`: join meetings by phone through an omnivoice-core voice gateway in audio mode ([`12831bb`](https://github.com/plexusone/omnimeet-core/commit/12831bb))
- `dialin.WithKeyDuration` joiner option ([`8d0790e`](https://github.com/plexusone/omnimeet-core/commit/8d0790e))
- `dialin/dialintest` package: simulated meetings with platform phone menus for tests ([`6e1c9f7`](https://github.com/plexusone/omnimeet-core/commit/6e1c9f7))
- `examples/dialin`: join a simulated meeting from an invite, record it, and leave ([`a25cb93`](https://github.com/plexusone/omnimeet-core/commit/a25cb93))

### Fixed

- `MeetingSkill` implements `Version`, required by omniskill's `Skill` interface ([`be386f7`](https://github.com/plexusone/omnimeet-core/commit/be386f7))

### Dependencies

## [v0.1.0] - 2026-07-04

### Highlights

- Initial release with unified abstractions for real-time collaboration platforms
- Provider-agnostic design supporting LiveKit with Daily and Zoom planned
- Agent skill interfaces for OmniAgent integration
- Voice integration types for STT/TTS via OmniVoice
